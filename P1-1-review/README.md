# P1-1 参考图语义有效性核查子集

VQA 和 SNLI-VE 各从现有 100 个实例中按原样本 ID 升序取前 20 个。每个实例保留原图和 20 张源参考、20 张目标参考，共 40 张原图、1,600 张参考图。VQA ID 范围为 `vqa_val_0000` 至 `vqa_val_0019`，SNLI-VE 为 `snli_ve_test_0000` 至 `snli_ve_test_0019`。

- `instances.jsonl` 是子集清单，包含问题或假设、源与目标答案或标签、生成提示词和相对文件路径。
- `samples/vqa/` 和 `samples/ve/` 按原样本 ID 保存原图、`bank.json`、两组参考图及随图语义审核记录。
- `metadata/*_20_生成前审核记录.json` 保存入选实例的提示词和审阅意见。现存记录载明为助手直接审阅。两个原始批次纪要和全库技术核验收据作为背景材料保留，适用范围见各原文件。
- `visual_model_semantic_audit_7b.jsonl` 是生成后的 Qwen2.5-VL-7B 视觉审核记录。`visual_model_semantic_audit_7b_text_review.jsonl` 保存对应的文本复判结果。两份记录均覆盖本子集的 1,600 张参考图，可按 `reference_id` 对照。
